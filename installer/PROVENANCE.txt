Comma setup installer for ANSR42/notautopilot branch cursor/stable-audit-report-1491.

What the comma setup screen accepts
  system/ui/tici_setup.py and system/ui/mici_setup.py download one URL and keep
  the body only when the first four bytes are the ELF magic 7f 45 4c 46. They
  then move that file to /tmp/installer. This is not a shell script.

Base artifact
  Public URL: https://installer.comma.ai/ANSR42/cursor%2Fstable-audit-report-1491
  Request: User-Agent AGNOSSetup-19.6, no X-openpilot-device-type header.
  SHA-256: ceb64a074a1a6d18bf0b9dc88d95e69582bc75b04229645a7f01b455c3a90ce7
  Size: 2051392 bytes
  ELF64, little endian, OS ABI GNU, AArch64, PIE, interpreter /lib/ld-linux-aarch64.so.1
  The same request with X-openpilot-device-type: mici returns HTTP 409 and the
  text "This version of openpilot is not compatible with this device." That
  check looks up https://github.com/ANSR42/openpilot, which is HTTP 404. No
  device header was invented to get past that response.

Patch
  installer/build_comma_installer.py replaces the single padded slot
  https://github.com/ANSR42/openpilot.git
  with
  https://github.com/ANSR42/notautopilot.git
  The slot is the '?'-terminated string in selfdrive/ui/installer/installer.cc.
  File size stays 2051392. The branch slot stays cursor/stable-audit-report-1491.
  Seventeen bytes differ, all inside that URL slot. No other bytes change.
  Output SHA-256: 40486647426c251fbb446e410f675533d8cdcb294d86cc083d7757d69b71e6e8

Fail-safe already in the upstream installer
  cloneFinished asserts the git command returned 0. A failed clone does not
  move a partial tree into /data/openpilot. branchMigration only renames
  release3 and release3-staging, so this branch name is not rewritten.

Dynamic dependencies, from readelf -d on this ELF (not from a text search)
  Interpreter: /lib/ld-linux-aarch64.so.1
  DT_NEEDED, in order:
    libGLESv2_adreno.so
    libEGL_adreno.so
    libgbm.so
    libstdc++.so.6
    libm.so.6
    libgcc_s.so.1
    libc.so.6
  The display backend recorded in the dynamic section is Adreno GLES/EGL plus
  GBM. libwayland is not a DT_NEEDED entry. That does not prove the program
  avoids Wayland, and it does not prove these SONAMEs exist on a device.

Two setup contracts in this tree

  Stock comma setup is system/ui/mici_setup.py and system/ui/tici_setup.py.
  It downloads the entered URL, requires ELF magic, and renames the file to
  /tmp/installer. For that contract, this ELF is the right file type and
  architecture, and the padded '?' slot is the customization described in
  selfdrive/ui/installer/installer.cc ("Leave some extra space for the fork
  installer") and implemented again by patch_padded_binary_slot in
  tools/agnos/patch_system_reset_image.py. The stock screen was not run.

  StarPilot's legacy image tool, tools/agnos/patch_system_reset_image.py,
  says it is only for auditing the previously published 19.6.13 image and
  that production images are built by agnos-builder, which is not in this
  repository. The patched setup it would write does not execute a downloaded
  installer.comma.ai ELF for an owner/branch URL. The comment at that
  replacement says that binary cannot run in that AGNOS. It copies
  /usr/comma/installer and rewrites only the slots
  https://github.com/firestar5683/openpilot.git and StarPilot, and the
  replacement URL is always https://github.com/<owner>/openpilot.git.
  The owner/branch regular expression does not match this branch, because
  the branch contains a slash. A full raw.githubusercontent.com URL therefore
  falls through to the download path that the same comment rejects.
  agnos-builder is absent, so the setup contract of a current production
  StarPilot image is not in this tree.

This ELF was not executed. Nothing here reads a device /VERSION or
/usr/comma/setup. Stock setup accepting an ELF does not establish that a
StarPilot AGNOS image will run this binary.

Read-only check before anyone enters the URL, from a shell already on the
device. This does not install, reset, or flash:

  cat /VERSION
  python3 -c 'p=open("/usr/comma/setup","rb").read(); print("patched_setup", b"file:///usr/comma/installer" in p)'
  readelf -d /usr/comma/installer | grep NEEDED

patched_setup True means the legacy bundled-installer setup is what will
run. This raw ELF is then the binary that patch declines to execute, and
the bundled slot cannot name notautopilot. patched_setup False means the
stock download-ELF setup is present; this URL matches that contract only.
Compare the NEEDED lines with the list above before treating the bundled
installer as the same binary.
